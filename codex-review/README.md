# Codex review

This directory records a read-only architectural review of `harness-openshell`.

- [Project status](project-status.md) captures the reviewed repository state and
  current architectural assessment.
- [Code recommendations](code-recommendations.md) lists prioritized engineering
  work needed to make the workflow contract reliable and maintainable.
- [ACS adoption architecture](acs-adoption-architecture.md) develops the
  organization-wide HyperShell/OpenShell adoption pattern.
- [Implementation plan](implementation-plan.md) sequences the next changes and
  defines acceptance criteria for the ACS pilot.

The review was based on source inspection. No builds or tests were run as part of
the review.
